Drop a folder to create a Mac app

Drop a project folder

App Dropper looks through the folder, figures out the project, and builds a double-clickable Mac app. If that folder has no start script, App Dropper writes one. The app is saved in App Dropper Apps, which you can put in the Dock and open the way you open the Applications stack, and it is installed in the Apps folder. If the app is already running, opening it again uses your default browser. If its port is taken, the launcher uses the next free port.
